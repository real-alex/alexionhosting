# Brand assets

Drop your Alexion Hosting brand files here. The dashboard references them by
filename, so keep these names (or update the references):

| File           | Used for                          | Recommended size |
| -------------- | --------------------------------- | ---------------- |
| `logo.svg`     | Top navigation / marketing header | vector           |
| `logo-mark.svg`| Square app icon / favicon source  | vector           |
| `favicon.ico`  | Browser tab icon                  | 32×32 / 48×48    |
| `og-image.png` | Social share preview              | 1200×630         |

Until you add a real logo, the dashboard shows a simple "A" monogram tile.

> These files are placeholders — replace them with your own artwork.
